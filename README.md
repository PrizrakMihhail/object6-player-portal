# Портал новых игроков Object 6

Путеводитель по миру игры, регистрация и личный кабинет. Описание игры и ссылки на разделы находятся в `src/index.html`. Страницы путеводителя по структуре «МОРДА.canvas» находятся в `src/world-history.html`, `src/object.html`, `src/object-history.html` и `src/team.html`. Стили «Осколка» хранятся в этом репозитории.

События страницы «История мира» находятся в `src/world-history-data.js`. Они идут по возрастанию года внутри каждого периода. Несколько карточек одного года выводятся под общей датой.

## Локальный запуск

Нужен Node.js 22 или новее. Выполните `npm run preview` и откройте `http://127.0.0.1:4174/`. Для локальной работы с аккаунтами скопируйте `.env.example` в `.env` и укажите URL и публичный ключ Supabase проекта Object 6.

## Публикация

В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Workflow **Deploy Player Portal** загружает сборку при отправке в `main`. Первый запуск можно выполнить вручную из вкладки **Actions**. Сайт публикуется по адресу `https://prizrakmihhail.github.io/object6-player-portal/`.

Сборка GitHub Pages использует публичный конфиг Supabase проекта Object 6 из `.github/workflows/pages.yml`. Для смены проекта задайте в переменных GitHub Actions этого репозитория `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`.

## Общая база Object 6

После настройки аккаунтов Object 6 выполните [SQL-миграцию](supabase/migrations/20261125090000_object6_player_portal.sql) в **SQL Editor** действующего проекта. При переносе портала уже применённую миграцию повторять не требуется.

Заявка создаёт запись в `object6_users` с игровой ролью `CITIZEN`, служебным именем пользователя и ID. Игрок входит по email и паролю и видит статус в кабинете. Telegram и фракция необязательны. Фракция в заявке — пожелание игрока. Подтверждение владения email и интерфейс обработки заявок пока отсутствуют.

Организатор может изменить `reg_status` в Supabase с `pending` на `approved` или `rejected`. Для активации входа существующего игрока организатор может указать подтверждённый email в его профиле. Игрок сможет использовать свой пароль от Сети.

Для отправки замечаний из бестиария примените в той же базе [миграцию гостевых сообщений](supabase/migrations/20261126130000_object6_bestiary_reports.sql) после миграции почты `20261123194500_object6_delete_messages.sql` из `object6-network`. Миграция разрешает пустое поле `from` и добавляет отдельную функцию отправки. Функция направляет замечания профилю с именем пользователя или номером документа `1984` и добавляет к теме «Перехват в Олегус: ». В почте получателя отправитель отображается как «Гость».
